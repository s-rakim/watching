Sheaf as an Android app. It's the same set of PDF tools as the web version, packed into an APK so it works offline with nothing to host.

**Install**

1. Download the `.apk` below on your phone or tablet.
2. Open it. Android will ask you to allow installs from your browser or file manager the first time.
3. Sheaf shows up in your app drawer.

Needs Android 7.0 or newer.

**Updates**

After this install, changes to Sheaf arrive by themselves: the app downloads them in the background and asks you to restart. Only changes to the Android side need a new APK, and the app tells you when that happens.

**Saving results**

Tap **Save** to put the file in `Documents/Sheaf`, or **Share** to send it to Drive, Files, mail or a chat app.

**Not in the app yet**

- DeepL translation needs the small relay server that `npm run serve` runs, so the app uses the on-device translator instead.
- If this APK was signed with a debug key (the build log says so), you'll need to uninstall it before installing a later build signed with the real key.
